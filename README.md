## How to Use

Read `SETUP.md` for the 5-minute quick start.

## Structure

- `wiki/` — PARA knowledge base (project → area → resource → archive)

- `todo/` — task backlog (1.todo.md pending, 3.done.md complete)
- `dailyNote/` — daily journals with work log
